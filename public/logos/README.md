# Logos (opcional)

Si tenés permiso para usar el escudo de un equipo, poné el archivo acá con el `id` del equipo
(ver `data/teams.json`) como nombre: por ejemplo `penarol.svg`, `nacional.png` o `boca-juniors.webp`.

Si no hay archivo, el juego muestra un escudo genérico con los colores y la sigla del equipo.
